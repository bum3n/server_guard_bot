# 🛡 Server Guard v2.0 — Центр управления и мониторинга VPS

**Server Guard** — это автономный Telegram-бот на Python (`pyTelegramBotAPI`), предназначенный для комплексного мониторинга состояния Linux-сервера (VPS), управления VPN-панелью 3X-UI, контроля системных служб, автоматического резервного копирования и защиты безопасности.

---

## 📂 Структура проекта

```text
server_guard/
├── main.py              # Главный модуль бота: клавиатура, обработчики сообщений, коллбэки и фоновый цикл
├── config.py            # Конфигурация: токен, списки служб/сайтов, пороги алертов, тарифы, .env
├── vpn_manager.py       # Интеграция с 3X-UI OpenAPI: клиенты, лимиты, подписки, QR-коды, управление доступом
├── analyzer.py          # Анализ системы: Fail2Ban (статистика/разбан), SSL (Let's Encrypt), Speedtest, SWAP, логи
├── backup_manager.py    # Резервное копирование: создание tar.gz, проверка целостности, ротация и разбивка
├── card_generator.py    # Генерирование графических карточек ресурсов и 24-часовых графиков истории (Matplotlib)
├── metrics_store.py     # Локальная база данных (SQLite) для сохранения истории метрик и сетевого трафика
├── security_tools.py    # Безопасность: отслеживание SSH-входов, ручной бан IP, интеграция с GeoIP
├── maintenance.py       # Обслуживание: Uptime, обновление пакетов apt, очистка диска, журналы служб
├── deploy.ps1           # PowerShell скрипт деплоя с автоматической валидацией кода на сервере
├── settings.json        # Файл пользовательских настроек бота на сервере (динамически создаётся)
├── metrics.db           # Локальная база SQLite для хранения точек истории ресурсов
├── server_guard.log     # Системный журнал работы бота (с автоматической ротацией)
└── .env                 # (Опционально) Переменные окружения и секретные токены
```

## ⚙️ Быстрый старт и конфигурация

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/bum3n/server_guard_bot.git
   cd server_guard_bot
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt # pyTelegramBotAPI psutil matplotlib requests qrcode[pil]
   ```

3. Настройте файл переменных окружения:
   ```bash
   cp .env.example .env
   nano .env
   ```
   Заполните `BOT_TOKEN`, `ADMIN_CHAT_ID`, `SERVER_IP`, `DOMAIN` и `XUI_API_TOKEN`.

4. Запустите бота или настройте системный сервис systemd:
   ```bash
   python3 main.py
   ```

## 🛠 Подробный разбор модулей и функций

### 1. `main.py` — Ядро и интерфейс Telegram-бота
- **Управление клавиатурами:**
  - `make_reply_keyboard()` — Главное меню из 8 управляющих кнопок.
  - `make_links_inline()` — Инлайн-сетка прямого перехода к веб-сервисам (2×3).
  - `make_services_inline()` — Инлайн-управление службами (Старт / Стоп / Рестарт / SSL / Обновление).
  - `make_client_view_keyboard()` — Карточка VPN-клиента с кнопками «В Happ», «Изменить», «Включить/Отключить», «Удалить» и «Назад».
  - `make_settings_main_inline()` — Меню настроек с тумблерами бэкапа, фильтров ОС, уведомлений SSH и отчётов.
- **Мастера сборок и состояний:**
  - `StateDict` — класс хранения состояний диалога с автоматическим таймаутом (10 минут) для заброшенных шагов.
- **Команды бота:**
  - `/start`, `/menu` — Активация бота, приветствие и вызов главного меню.
  - `/status` — Вывод графической карточки текущих ресурсов и системного статуса.
  - `/chart` — Отображение 24-часового графика истории CPU, RAM, Disk и сетевого трафика.
  - `/backup` — Немедленное создание и отправка резервной копии сервера.
  - `/speedtest` — Запуск замера интернет-канала VPS (Ookla Speedtest).
  - `/logs` — Просмотр реальных системных ошибок за 24 часа из `journalctl`.
  - `/unban <IP>` — Команда моментального разбана IP-адреса в Fail2Ban.
  - `/help` — Подробная справка по всем возможностям бота.
- **Фоновый поток `monitoring_loop()`:**
  - Опрашивает ресурсы системы каждые 3 секунды.
  - Учитывает сетевой трафик (входящий/исходящий КБ/с) и сохраняет метрики в `metrics_store`.
  - При постоянной нагрузке CPU (>85% в течение 12 сек) или превышении RAM/Disk (>90%) отправляет тревожный алерт админам.
  - Автоматически отфильтровывает технические фоновые всплески от обновлений Ubuntu (`apt`, `dpkg`, `unattended-upgrades`).
  - Фиксирует падение служб systemd и присылает алерт с кнопками быстрого восстановления.
  - Осуществляет проверку новых SSH-входов, ежедневных автобэкапов и срока действия SSL-сертификата.

### 2. `vpn_manager.py` — Интеграция с 3X-UI (Xray / Reality / Hysteria)
- Работа через официальный OpenAPI 3X-UI и прокси Nginx (`/3x-ui-panel/`).
- `login()` — Сессионная авторизация в панели 3X-UI через POST `/login`.
- `get_clients_list()` — Получение списка всех VPN-клиентов через REST API 3X-UI (`GET /panel/api/clients/list`).
- `create_client()` — Создание нового клиента сразу в 4 целевых инбаундах (inboundIds: 1, 2, 3, 5) с выбором лимита ГБ и срока действия в днях.
- `set_client_enabled()` — Мгновенная блокировка / разблокировка клиента в панели без удаления.
- `update_client_limits()` — Редактирование лимитов трафика (ГБ) и срока действия (дни) для существующего клиента.
- `extend_client()` — Быстрое продление срока или добавление пакета трафика.
- `delete_client()` — Удаление клиента во всех инбаундах с каскадной очисткой.
- `build_links()` — Генерация чистой подписки 3X-UI (`https://{domain}/{sub_path}/{sub_id}`) и ссылки веб-шлюза (`/redirect_happ/?token=...`).
- `build_happ_deeplink()` — Построение прямого deep-link протокола Happ (`happ://add/...`) для мгновенного импорта.
- `generate_qr_bytes()` — Формирование PNG-картинки с QR-кодом подписки.

---

### 3. `analyzer.py` — Системная аналитика и обслуживание
- `flush_swap()` — Безопасная выгрузка файла подкачки (SWAP) в оперативную память (`swapoff -a && swapon -a`). Включает предпроверку объема доступной ОЗУ для защиты от срабатывания OOM Killer.
- `get_fail2ban_stats()` — Сбор статистики блокировок SSH-атак (активные баны, общее количество, список забаненных IP).
- `unban_ip()` — Снятие блокировки с IP через `fail2ban-client`.
- `check_ssl_expiry()` — Проверка срока действия боевого сертификата Let's Encrypt для активного домена (`/etc/letsencrypt/live/{domain}/fullchain.pem`) с откатом на IP-сертификат.
- `renew_ssl()` — Безопасное автоматическое продление сертификата acme.sh с временной остановкой Nginx и гарантированным перезапуском всех веб-служб.
- `run_speedtest()` — Тестирование входящей и исходящей скорости канала через `speedtest-cli`.
- `get_critical_logs()` — Фильтрация журнала `journalctl` за последние 24 часа без сетевого шума (handshake, SSLv2 и т.д.).

---

### 4. `backup_manager.py` — Резервное копирование
- **Состав архива (`BACKUP_PATHS`):**
  - База 3X-UI (`x-ui.db`), сертификаты Let's Encrypt, SSH-ключи (`authorized_keys`).
  - WARP профили (`wgcf-account.toml`, `wgcf-profile.conf`).
  - Конфигурация и сайты Nginx (`nginx.conf`, `/var/www/html`).
  - Юниты автозапуска systemd (server_guard, mem_bot, flashcard_bot, jupyter, wireproxy, anonchat).
  - Исходные коды проектов и базы данных (bot-проекты, учебные тетрадки `/notebooks`).
- **Функции:**
  - `make_backup_archive()` — Создание архива `.tar.gz` с исключением тяжёлых папок (`venv`, `node_modules`, `__pycache__`).
  - `verify_archive()` — Валидация целостности созданного файла архива.
  - `save_local_copy()` — Сохранение ротационной копии на сервере (хранится 7 последних бэкапов в `/root/backups`).
  - `split_file()` — Автоматическая разбивка архивов крупнее 49 МБ на части для отправки через Telegram API.

---

### 5. `card_generator.py` & `metrics_store.py` — Визуализация и База данных
- `metrics_store.py`:
  - SQLite хранилище `metrics.db`.
  - Автоматическое сохранение точек CPU, RAM, Swap, Disk и сетевой скорости (вх/исх КБ/с).
  - Хранение истории за последние 8 дней с автоматической очисткой старых точек.
  - Выборка и агрегация данных (`get_summary()`).
- `card_generator.py`:
  - `generate_status_card()` — Генерация красивой темной картинки со шкалами загрузки ресурсов, пороговыми линиями (65% и 85%) и аптаймом.
  - `generate_history_chart()` — Генерация двухсекционного графика (нагрузка в % и сетевой трафик в КБ/с) за 24 часа.

---

### 6. `security_tools.py` — Безопасность и Геолокация
- `get_ssh_logins_since()` — Выборка успешных входов по SSH с автоматической дедупликацией сообщений.
- `geoip()` — Определение страны, города и провайдера по IP-адресу через API.
- `ban_ip()` — Ручная блокировка подозрительных IP через Fail2Ban.

---

### 7. `maintenance.py` — Обслуживание сервера
- `get_uptime_seconds()`, `format_duration()` — Расчет и форматирование времени непрерывной работы VPS.
- `check_port()` — Проверка локальных TCP-портов (80, 443, 44506, 8443).
- `count_upgradable()`, `run_upgrade()` — Проверка и установка обновлений системы (`apt`).
- `get_disk_report()`, `cleanup_disk()` — Анализ дискового пространства и очистка кэша `apt` / старых логов.
- `get_service_logs()` — Выборка журналов конкретной службы systemd.

## 🚀 Деплой на сервер

Для автоматического обновления бота на сервере используйте готовый скрипт:

```powershell
.\deploy.ps1
```

**Этапы деплоя:**
1. Локальная проверка синтаксиса всех модулей.
2. Загрузка во временную директорию на сервере по SSH/SCP.
3. Удалённая проверка синтаксиса на сервере Python-интерпретатором.
4. Замена рабочих файлов в `/root/server_guard/` и перезапуск службы `systemctl restart server_guard`.
5. Проверка статуса службы (`systemctl is-active server_guard`).
